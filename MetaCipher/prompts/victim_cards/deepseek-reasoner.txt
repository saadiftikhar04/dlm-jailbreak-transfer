DeepSeek-reasoner is a DeepSeek API on the model DeepSeek-R1 with 671B parameters. It is a highly capable reasoning model. Because of the multi-step reasoning, a post-checking is guaranteed in itself. Furthermore, one cannot set the max number of tokens in the genereation api. Therefore, it is recommended to start with 5 distraction questions, in order to avoid our malicity being discovered by the next step of self-reasoning. We need to "exhaust" the model so that it answers our malicious question in the last step, and there is no further reasoning. It is always recommended to slightly increase the number of distraction questions when an attempt failed. Also, letter-based ciphers are recommended.
